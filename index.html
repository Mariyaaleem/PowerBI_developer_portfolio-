What I check when a report feels slow:


Remove unused columns in Power Query so the model stays small. Use measures instead of calculated columns where possible. Keep relationships single-direction on a star schema. Limit visuals per page and test heavy ones in Performance Analyzer. Use DIVIDE for safe ratios and variables in DAX to avoid repeated calculation.
